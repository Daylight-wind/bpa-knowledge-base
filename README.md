可直接双击打开 `页面原型/index.html`，脚本使用本地文件，不需要安装依赖。

也可以在本项目目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory 页面原型
```

然后浏览器访问 `http://127.0.0.1:8768`。仅绑定本机，不对局域网开放。按 Ctrl+C 停止。该预览命令不是正式内网部署方案。

## Markdown 文章试点（本地草稿）

“制度、流程、规范与指导书有什么区别”已接入 Markdown。编辑内容库中对应文章，保存后在本项目目录执行：

```sh
python3 scripts/build_markdown_pilot.py
```

然后刷新 `页面原型/index.html`。试点文章的正文、表格、图片和搜索内容会更新；网页标题优先使用正文中的第一个一级标题（以 `# ` 开头），没有一级标题时使用顶部 `title` 属性。试点文章中的内部链接指向的草稿也会一起生成，其他未链接的文章仍使用原型数据。支持常用 Markdown 格式、内容库内相对路径图片、Obsidian 图片嵌入、内部笔记和标题链接。内部链接目标必须有完整的文章属性且状态为 draft；找不到或重名时生成会报错，不会替换现有网页数据。

此命令仅用于本地草稿预览，不是正式发布流程。生成文件位于 `页面原型/generated/markdown-pilot.js` 与 `页面原型/generated/pilot-assets/`，不要直接编辑；原始 Markdown 和图片不会被覆盖。生成失败时，请根据提示检查文章元数据和图片路径。

### 在 Obsidian 里一键更新试点网页

本内容库附带本地桌面插件“BPA 网页内容更新”。在 Obsidian 打开本项目的 `流程管理平台学习内容库` 后，若首次使用时看不到按钮，请在“设置 → 第三方插件”中关闭安全模式（受限模式），并启用“BPA 网页内容更新”。

编辑并保存试点文章后，点击左侧工具栏的循环箭头（鼠标悬停显示“更新 BPA 网页试点文章”），或通过命令面板执行同名命令；出现成功提示后刷新网页。如果更新失败，Obsidian 会显示错误详情。命令面板中的命令也可以在“设置 → 快捷键”中自行设置键盘快捷键。插件仅运行本项目的本地试点构建脚本，不上传内容；未链接的其他文章和正式发布流程尚未接入。


#### 当前转换边界

- 解析库已随项目保存，不需要联网安装；网页是本地草稿预览，不是正式发布包。内部链接引用的笔记及图片会加入生成结果，可能在预览的目录和搜索中出现。
- 支持常规标题、段落、粗体、斜体、删除线、引用、列表、表格、代码、普通网页链接、Markdown 图片链接、Obsidian `![[图片.png]]`（支持数字宽度）、`[[笔记|别名]]` 和 `[[笔记#标题]]`。同名文件或标题不唯一、路径无效时会停止生成并说明原因。
- 暂不支持 Obsidian 块链接和嵌入整篇笔记、Callout 专用样式、Mermaid 图表、公式、任务框交互、音视频或 PDF 嵌入、远程图片等；正文中的 HTML 会转成文字显示。复杂格式请先在网页预览核对。
- 双向链接、关系图、动态查询与各类插件的视图是 Obsidian 功能，不会自动转换为网页。内部链接目标笔记须含必需元数据（id、title、category、audience、status）；本阶段只接收 draft。
- 网页标题以第一个一级标题为准；不支持的语法不保证与 Obsidian 显示完全一致。格式、图片与业务内容发布前仍需逐项审核。
