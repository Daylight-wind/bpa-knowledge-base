# 3.0 从新建到发布一份流程文件

## 1. 新建流程节点

1. 先登录“流程管理平台”，登录方式见[[2.1 系统登录入口]]

2. 登录后进入“我的工作台”
   ![[Pasted image 20261118145236.png]]

3. 选择“流程建设”，左侧目录会展示有编辑权限的流程架构，若没有找到目标架构，请联系 IT-流程管理部开通架构权限

4. 选中架构，点击新建按钮，可以新建“架构”、“节点”。（“架构”可以理解成文件夹，“流程”就是“架构“下的子文件。

![[Pasted image 20261118150512.png]]

5. 新建”流程“，点击流程侧的按钮，可以对流程的名称和权限进行编辑，在编写流程的过程中，要记得经常”暂时保存“文件，避免文件丢失。若本地已有流程图文件，也可以点击”智能助手“完成文件的快速导入。

![[Pasted image 20261118151549.png]]

5. 关联岗位
角色关联岗位或者岗位组，岗位和岗位组可同时存在。
流程发布后，关联岗位和岗位组的对应人员可在门户端——我的岗位——工作职责查看该流程，无需另设置查看权限。若需关联岗位/岗位组之外的人员查看流程，需另外设置查看权限，参考[[3.1 流程节点与权限管理#3.1.3 节点权限管理|节点权限管理]]。

## 4. 关联上下游流程

若该流程需要关联其他流程，那么选择“流程关联”组件，在基本属性中关联其他流程即可。

![[Pasted image 20261113160707.png]]


## 5. 关联相关文件

点击流程信息的【相关文件】模块，点击关联文件即可。

![[Pasted image 20261113160730.png]]

![[Pasted image 20261113160742.png]]

## 6. 填写流程属性与内容

需要将【文件内容】中的“基础属性”必填项全部填写，并注意是否需要改动文件编码中的公司代码。

![[Pasted image 20261113155413.png]]

选择人员时，选择正常的岗位+姓名组合，不要选全体岗位+姓名

![[Pasted image 20261113155501.png]]



## 7. 增加文件历史版本修订记录

增加文件历史版本修订记录
历史文件初次编写时，需将历史版本修订记录手工增加到系统。
规则：大版本号在上，小版本号在下，版本号都为整数。
如图展示：

## 8. 流程文件发布
❗️注意事项：
1. 一旦进入审批提交页面，==流程画布将会被锁定不可编辑修改==，故务必流程编写完善后再点击进入审批页面，若进入了审批页面且在提交之前仍需修改流程内容，请联系流程管理部。
2. 若会签人已在【责任人、审核人、批准人】中包含，则无需再另外选择作为会签人。
