# 3.2 流程文件属性与保存

## 3.2.1 流程文件属性
| 名称      | 说明                                                                      |
| ------- | ----------------------------------------------------------------------- |
| 流程目的    | 描述制定流程的目的和初衷<br><br>例如:“为了规范xx工作/事项，缩短xx工作周期，防范xx风险，提升xx能力或水平，特制定xx流程。” |
| 流程范围    | 这里的“范围”包含两个维度:一是组织范围;二是业务范围，                                            |
| 术语/定义   | 对在流程中出现的相关术语或名词进行解释，                                                    |
| 角色职责    | 对各角色在流程中承担的职责进行描述                                                       |
| 流程输入/输出 | 流程的输入，即触发流程启动的条件<br><br>流程的输出，即流程执行完成后的结果                               |
| 流程KPI   | (1)效率。流程周期、流程单位成本、流程决策效率等。<br>(2)效果。返工率、缺陷率、客户满意度等。                     |

## 3.2.2 流程保存
❗️为防止数据丢失，编辑文件时，最好边做边“暂时保存”，保存成功会有提示信息并生成一个编辑版本。
