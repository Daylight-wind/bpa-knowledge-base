# 4.1 从新建到发布一份制度文件

## 4.1.1 新建制度

新建路径：进入工作台 → 文件编制 → 制度管理。

![[Pasted image 20261113165154.png]]

新建制度文件的操作与新建流程相似，节点管理方式也相似。

1. 选中某一架构
2. 新建制度
3. 重命名制度名称
4. 点击进入进行编辑

❗**特别事项：** ==除流程文件外，制度等文件不需设置查看权限，发布后默认为全员可看；若有需要，可设置排除查看权限。==

## 4.1.3 段落样式

在流程管理平台中编写制度、指导书等文件时，可以粘贴其他地方的文字，但**粘贴后必须清除原有格式**，如下图所示。正文无需在系统中另外设置首行缩进、段前空格等格式。

![[Pasted image 20261113165527.png]]


## 4.1.4 插入表格

如需插入表格，请点击下图所示位置，选择表格的列数和行数。

![[Pasted image 20261113165626.png]]

需要编辑表格时，将鼠标光标放在表格内，在弹出的操作栏中进行操作。

若预览文件时表格与页面不协调，可点击【表格属性】，将宽度比例调整为 100%。

![[Pasted image 20261113165639.png]]

![[Pasted image 20261113165650.png]]

## 4.1.5 填写制度属性与内容

填写【文件内容】中“基础属性”的所有必填项，并注意是否需要修改文件编码中的公司代码。下图展示的是新建流程时需要填写的文件内容，供操作参考；这部分操作与编写流程相似，具体可查看[[3.0 从新建到发布一份流程文件#6. 填写流程属性与内容|填写流程属性与内容]]。

![[Pasted image 20261118170411.png]]

选择人员时，选择正常的“岗位 + 姓名”组合，不要选择“全体岗位 + 姓名”。

![[Pasted image 20261113155501.png]]

## 4.1.6 增加文件历史版本修订记录

历史文件初次编写时，需将历史版本修订记录手工增加到系统。规则是大版本号在上、小版本号在下，版本号均为整数。也可参考流程案例中的[[3.0 从新建到发布一份流程文件#7. 增加文件历史版本修订记录|历史版本修订记录]]。

![[Pasted image 20261113161032.png]]


## 4.1.7 制度文件发布

==制度文件发布与流程文件相似。下图采用流程文件发布操作截图，特殊操作另行说明。==

**提交前注意：**

1. 一旦进入审批提交页面，==内容将会被锁定不可编辑修改==，故务必编写完善后再点击进入审批页面，若进入了审批页面且在提交之前仍需修改内容，请联系流程管理部。
2. 若会签人已在【责任人、审核人、批准人】中包含，则无需再另外选择作为会签人。

![[Pasted image 20261113160926.png]]

![[Pasted image 20261113161106.png]]


❗**与流程文件的区别：**

==制度、规范/标准及指导书文件，审批发布提交页面增加“文件发布通知部门范围”==

注意：此处仅可选取部门维度，不可选择岗位或具体人员。

文件审批归档之后，选择的部门下人员会在企业微信接收到该文件的发布通知和学习任务。
