# 2.2 门户与工作台介绍

> 员工使用门户查阅内容；具有相应权限的人员可以进入工作台编制和维护内容。

![门户查阅与工作台维护的概念示意](../../assets/portal-workbench-illustrations/01-portal-workbench.png)

## 2.2.1 门户：面向查阅与使用

门户主要用于查看与自己有关的流程、制度和文件。普通员工不需要学习完整的 PO 编制操作，也不需要因为看不到编辑入口而判断系统异常。

## 2.2.2 工作台：面向编制与维护

工作台主要供具有相应权限的人员编制和维护相关文件。能否进入工作台、能看到哪些功能，取决于账号权限。

| 我现在想做什么      | 优先看哪里            |
| ------------ | ---------------- |
| 查一个流程或制度     | 门户               |
| 查看与岗位有关的内容   | 门户               |
| 查看本人负责或拟制的文件 | 门户中的相关区域，具体以现网为准 |
| 编写或维护流程文件    | 工作台，需具备相应权限      |

## 2.2.3 门户介绍
通过登录入口进入平台后，首先看到的是门户页面。门户作为平台的展示端首页，汇总与当前登录人员相关的信息，包括：

- 岗位工作职责：参与流程、担任角色和职责内容；
- 相关要素：角色、风险、指标、术语和条款；
- 学习任务和审批待办；
- 负责文件和拟制文件：包括流程文件、制度、规范 / 标准、指导书等。

## 2.2.5 工作台权限申请

申请工作台权限时，提交《IT013-新-ERP系统权限开通申请》流程：

1. 开通权限类型选择“增加/修改权限”。
2. 开通系统选择“流程管理平台”。
3. 详细填写需要开通的流程架构名称。
![[Pasted image 20261113113805.png]]

## 2.2.6 架构卡管理

维护架构卡时，需要填写简称、责任人、责任部门等必填项，并编写流程定义、流程目的等内容。

- 文件编码自动生成规则：公司代码 + 文件类型 + 一级架构简称 + 二级架构简称 + 流水号。
- 架构卡发布后，架构卡下的文件内容才可以发布和查看。
