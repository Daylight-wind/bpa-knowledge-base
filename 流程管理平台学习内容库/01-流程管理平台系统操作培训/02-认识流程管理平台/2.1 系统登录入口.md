# 2.1 系统登录入口

流程管理平台有两个登录入口：EHR 系统和企业微信。

## 2.1.1 通过 EHR 系统登录

依次进入 **EHR 系统 → 资源文件 → 流程与文件**，即可进入流程管理平台。

![[Pasted image 20261113111218.png]]

## 2.1.2 通过企业微信登录

依次进入 **企业微信 → 工作台 → IT系统 → 流程管理平台**。

![[Pasted image 20261113111353.png]]

## 2.1.3 账号与密码

![[Pasted image 20261113114039.png]]

- 登录账号可以选择使用自己的中文拼音或工号。
- 初始密码的安全获取渠道待确认，请勿使用他人账号。
- 当天入职的员工，系统账号第二天才会自动生效，需要第二天才能登录系统。
