# 登录流程管理平台

## 两种登录方式

流程管理平台有两个登录入口：

1. **通过 EHR**：依次进入 EHR 系统 → 资源文件 → 流程与文件，即可进入流程管理平台。

![[Pasted image 20261113111218.png]]

2. **通过企业微信**：依次进入企业微信 → 工作台 → IT系统 → 流程管理平台。

![[Pasted image 20261113111353.png]]

## 账号与密码

- 登录账号可以选择使用自己的中文拼音或工号。
- 初始密码若忘记，请联系 **IT-流程管理部**获取。
- 当天入职的员工，系统账号第二天才会自动生效，需要第二天才能登录系统。

![[Pasted image 20261113114039.png]]

## ❓登录遇到问题

确认自己使用的是本人账号；如无法登录，请联系IT-流程管理部，并说明所用入口和页面提示。
