# 流程管理平台学习内容库

这是流程管理平台学习与操作中心的内容源，建议使用 Obsidian 打开本文件夹作为 Vault。

## 内容状态

- `draft`：草稿，仅用于内容整理
- `review`：待业务审核，不对全公司发布
- `published`：已审核，可发布到内网网页
- `deprecated`：已废止，不再作为当前内容

当前内容均为 `draft`，不代表正式 SOP。

## 维护原则

1. 先确认资料来源，再整理内容；未核验的系统按钮、权限和流程规则不得自行补全。
2. 每篇内容保留来源、适用对象、状态和最后更新时间。
3. 课程内容按培训链路组织，操作指南按任务组织。
4. 修改内容优先编辑 Markdown，不直接修改网页代码。
