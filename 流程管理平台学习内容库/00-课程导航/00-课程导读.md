# 流程管理平台系统操作培训

本课程面向具有文件编辑权限的人员，包括 PO（流程负责人）及流程管理部管理员。建议先了解流程管理和平台，再结合实际工作学习文件编写与维护；管理员操作另行整理。
## 适用范围

适合承担流程管理平台文件编写或维护工作的人员入门学习。是否能够使用某项功能，仍以本人账号的实际权限为准。

## 学习目标

学完之后，你应该能够：

- 理解制度、流程、规范与指导书的区别；
- 知道流程管理平台各入口分别用于什么；
- 明确流程负责人在流程建设和维护中的职责；
- 了解流程文件、制度文件、表单与附件的编写逻辑。

## 建议学习方式

建议按照模块顺序学习。如果只是查找某个具体操作，可以直接进入“操作指南”。

```text
理解流程管理 → 认识流程管理平台 → 学习编写与维护
```

## 课程模块

1. 流程管理基础
2. 认识流程管理平台
3. 流程文件编写指导
4. 制度文件编写指导
5. 表单与附件
6. 管理员操作

可按照模块顺序学习，也可以通过操作指南按任务查阅。各项操作以实际权限和现网为准。
